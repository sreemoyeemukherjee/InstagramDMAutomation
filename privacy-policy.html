Privacy Policy — InstaDMAutomation

Effective date: July 20, 2026

InstaDMAutomation is a personal, independently-operated automation tool that replies to Instagram comments on a single creator's own account. This policy explains what data the tool processes and how.

What the tool does

When someone comments a specific keyword on a reel/post, the tool:

  • Reads the comment's text and its Instagram-assigned comment ID.
  • Sends a private reply (DM) and a short public reply acknowledging the comment.

What data is processed

Only the data needed to generate and send that single reply:

  • The comment's text content.
  • The comment's Instagram-assigned ID (used only to address the reply — not a general user identifier).
  • The reel/post's topic, used to make the reply relevant.

Third-party processing

Comment text is sent to Anthropic's Claude model, hosted on AWS Bedrock, solely to draft the reply text. It is not stored by that service beyond the single request used to generate a response.

What is NOT collected

  • No passwords, payment information, or financial data.
  • No browsing history or data from outside Instagram.
  • No data is sold, shared with advertisers, or used for purposes other than generating the automated reply.

Data retention

The tool does not maintain a database of commenters or their messages. Each comment is processed to generate one reply and is not stored afterward, beyond standard operational logs used for debugging, which are periodically cleared.

Your rights

If you have questions about this policy, or want any data related to your interaction with this tool addressed, contact the operator using the details below.

Changes to this policy
